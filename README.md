# Rehan Desai — Personal Design Profile & Portfolio

A minimalist, editorial personal portfolio website designed for a creative software engineer. Built with vanilla HTML5, CSS3, and JavaScript—focusing on refined typography, intentional whitespace, and fluid micro-interactions.

---

## ✦ Key Features

* **Editorial Visual System**: Warm, neutral color palette (`#F6F4EF`) paired with clean typographic hierarchy and generous whitespace.
* **Interactive Hover Image Previews**: Floating project previews dynamically track mouse movement across selected works.
* **Soft Color Accents**: Contextual pastel highlights on project interactions (soft blue, green, and yellow palettes).
* **Native Scroll Reveals**: Powered by a lightweight `IntersectionObserver` for performant, staggered entrance animations.
* **Custom Cursor**: Hardware-accelerated cursor with hover states and automatic fallback on touch-enabled devices.
* **Accessibility**: Native support for `prefers-reduced-motion` and responsive layout scaling across mobile, tablet, and desktop viewports.
* **Zero Dependencies**: Pure vanilla HTML/CSS/JS without heavy UI frameworks, bundlers, or third-party runtime libraries.

---

## ✦ Tech Stack

* **Structure**: Semantic HTML5
* **Styling**: Modern CSS3 (CSS Variables, CSS Grid, Flexbox, Clamp typography)
* **Interactivity**: Vanilla JavaScript (ES6+, `IntersectionObserver`, Pointer Events)
* **Fonts**: System & Editorial Helvetica Neue stack
